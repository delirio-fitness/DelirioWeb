# Google Trends Queries — Run These Yourself

**Last updated:** 2026-09-04

Google Trends requires a browser to render its data (JavaScript-heavy, no public API). These are the exact comparison queries to run at https://trends.google.com/trends/explore, organized by purpose. Set location to **United States** and time range to **Past 12 months** for current relevance, then switch to **Past 5 years** to see sustained trends.

Copy-paste each URL into your browser.

---

## Query 1: GLP-1 drug name popularity (which brand name to lead with)

```
https://trends.google.com/trends/explore?geo=US&q=ozempic,wegovy,mounjaro,zepbound,glp-1&hl=en
```

**What to look for:** Which drug name has the highest sustained search volume. Use the winner as the lead keyword in your GLP-1 content (e.g., "Strength Training on [Winner]" as the primary title, others as secondary pages).

## How to read Google Trends results

- **Numbers are relative (0-100)**, not absolute search volumes. 100 = peak popularity in the time range, everything else is relative to that.
- **Compare within the same query only.** A score of 50 for "ozempic" doesn't mean the same volume as 50 for "ai fitness coach" — they're on different scales.
- **"Related queries"** at the bottom are the most actionable output. "Rising" queries show what's growing fast. "Top" queries show consistent volume.
- **Use "Past 5 years" view** to see if a trend is growing, stable, or declining. For base keywords, you want stable or growing.
