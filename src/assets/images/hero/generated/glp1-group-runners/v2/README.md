# GLP-1 Group Runners Hero, V2

This folder contains the revised generated background used by the default landing-page hero.

## Files

- `image.png`: lossless 2048 by 1152 generation output.
- `image.jpg`: web-optimized production asset at the same dimensions.
- `prompt.txt`: exact prompt submitted for generation.

## Revision goals

- Show a balanced range of ordinary adult body types rather than making every runner plus-size or highly athletic.
- Pull the camera farther back so every runner is fully visible and the scene has more environmental context.
- Preserve a calm, dark left region for readable hero copy.

## Provenance

- Generated from text with OpenAI `gpt-image-2` through the project image-generation CLI.
- No stock photograph or other image was supplied to the model as an input.
- The prompt explicitly requires an original setting, people, wardrobe, arrangement, and camera composition.
- V1 remains in the adjacent `v1` folder as a reversible design baseline.

This provenance reduces dependency on third-party stock licensing. It is not a substitute for final legal review of public marketing assets.
