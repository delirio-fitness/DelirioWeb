
  # Delirio Website

  Run `npm i` to install the dependencies.

  Run `npm run dev` to start the development server.

  Run `npm run build` to create the deployable, pre-rendered SEO build, then
  `npm run test:seo` to validate its crawl files and route metadata. See
  [`docs/seo.md`](./docs/seo.md) for the release and Search Console checklist.
